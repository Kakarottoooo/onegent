## Codebase Patterns

- Two-layer execution: AI (Stagehand/stagehand.act()) first, Playwright RPA fallback
- All browser automation flows through lib/booking-autopilot/stagehand-executor.ts
- Stage detection uses Claude Haiku perception (AI_LOOP_STAGE_DETECT) + rule-based signals
- Payment forms are always RPA-only (cross-origin iframe blocks AI access)
- React inputs require nativeSetter + input/change events — locator.fill() alone doesn't trigger React state
- Provider-specific code lives in lib/booking-autopilot/providers/
- booking-com.ts has ~2900 lines — read only the sections you need, not the whole file
- AI_LOOP_FULL=true enables all AI phases; individual flags: AI_LOOP_STAGE_DETECT, AI_LOOP_LISTING, AI_LOOP_FORM_FILL
- liveLogPush(jobId, line) for real-time log streaming; trace() calls this automatically
